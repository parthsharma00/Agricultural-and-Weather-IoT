# Agricultural & Environmental Weather Station IoT System

An integrated firmware ecosystem engineered for geospatial telemetry, localized meteorological monitoring, and agricultural automation frameworks.

## 🛰️ Monitored Subsystems & Telemetry
- **GPS Coordinates Processing:** Real-time parsing of NMEA sentence structures to capture latitude, longitude, and altitude matrices.
- **Digital Magnetometer / Compass Integration:** Computes true heading calculations relative to magnetic interference fields.
- **Weather Station Suite:** Multi-sensor configurations logging localized microclimate variations (including ambient temperature, barometric pressure, and luminous flux using Light Dependent Resistors).

## 🛠️ Hardware Stack
- Developed using low-power IoT microcontrollers, integrated over I2C, SPI, and hardware UART data links.
